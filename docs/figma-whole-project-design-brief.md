# Church CMS Figma Handoff

This is the whole-project design pass for the Core PHP Church CMS. The importable board is:

`docs/figma-whole-project-design-board.svg`

## What Is Covered

- Unified login for admin roles and department heads.
- Admin shell with fixed royal sidebar, sticky header, theme verse card, role-aware nav, and user footer.
- Dashboard with church calendar, upcoming events, Last Sunday summary, church overview, and finance snapshot.
- Members and guest registry with KPI cards, filters, import/export actions, table rows, and add-member modal.
- Attendance, finance, sadaka, procurement, assets, communication, settings, reports, and zones as project modules.
- Department portal shell with dashboard, members, leaders, finance, reports, contributions, and assets.
- Mobile responsive pattern for drawer nav, stacked KPIs, scrollable tables, and full-screen modal behavior.

## Design Tokens

- Royal: `#1c1847`, `#2c2277`, `#4f36d8`
- Dawn: `#2878f5`
- Glory: `#f5ad0d`, `#d98506`
- Mist: `#f8f8fb`, `#f2f2f8`, `#d4d6e4`, `#606884`
- Semantic: success `#059669`, danger `#dc2626`, table border `#e6e7f0`
- Headings follow the app's Cormorant Garamond intent; body/UI text follows Nunito/system sans.
